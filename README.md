Starting up the things:
- Backend:
   - python3 -m venv .venv
   - source .venv/bin/activate
   - python -m pip install -r requirements.txt
   - python app.py
- Frontend
   - cd DevOPS/secnote-frontend
   - npm install
   - npm run dev

Connect the two with the following adress -> http://127.0.0.1:8000
